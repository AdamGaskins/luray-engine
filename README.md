# Luray Engine - Lua + Raylib

Prealpha

Usage

```sh
luray init project # Scaffolds a new project, including lua type definitions
cd project
luray dev # Runs with hotreloading
luray export # Exports to all platforms (including web!) with one command
```

## Installation

Homebrew is the recommended install method:

```sh
brew tap AdamGaskins/luray-engine https://github.com/AdamGaskins/luray-engine
brew trust --formula AdamGaskins/luray-engine/luray-engine
brew install luray-engine
```

```sh
luray
```

You're also welcome to install manually by downloading the zip from releases. It
is a single binary that you can copy to your bin folder:

```sh
cp luray /usr/local/bin/luray
```
